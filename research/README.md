# Research

کد اکتشافی و آزمایشی. اینجا خطر کردن و کد کثیف نوشتن مجاز است — اما وقتی چیزی
به نتیجهٔ پایدار رسید، باید به‌صورت تمیز به `engine/` منتقل شود، نه این‌که همین‌جا
"موقتاً برای همیشه" بماند.

- `crps-loss/`: تحقیق روی توابع loss جدید برای پیش‌بینی توزیع بازده مالی.
- `prototypes/`: پیاده‌سازی‌های اولیه/آموزشی (LSTM ساده، toy diffusion models).
